# cs230-task1

A four-page, HTML-only website about songwriting.

## Files
- `index.html` — home page and figure/caption
- `process.html` — songwriting process and semantic data table
- `influences.html` — active listening guide
- `resources.html` — external links and practice plan

## Requirements demonstrated
- HTML5 doctype, `html`, `head`, and `body`
- Four linked pages and external links
- Semantic `header`, `nav`, `main`, `section`, and `footer` elements
- Logical heading hierarchy, lists, image alt text, `figure`, and `figcaption`
- Accessible table with caption, table header groups, and row/column scopes
- No CSS and no JavaScript

The home page's image is loaded from an external image URL, so an internet connection is required to display it.
