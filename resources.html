Useful starting points

These external resources can help you learn about music, language, and creative practice.

  • Library of Congress — collections and cultural history.
  • GRAMMY.com — music news, features, and interviews.
  • Poetry Foundation — poems and writing inspiration.

A weekly practice plan

  1. Choose one song and listen without multitasking.
  2. Write down three details about its lyrics or arrangement.
  3. Draft eight lines inspired by a technique you noticed.
  4. Revise the draft and save both versions to track your progress.

About this project

Songcraft is a small HTML-only website made to demonstrate document structure, navigation, semantic content, accessible image text, and a data table. It uses no CSS and no JavaScript.
